# Fonts

Latin subsets of the two typefaces the CommitFlex app uses, so the popup,
options page and in-page panels match it:

- `schibsted-grotesk-latin.woff2`: Schibsted Grotesk (variable, weights 400 to 900)
- `jetbrains-mono-latin.woff2`: JetBrains Mono (variable, weights 100 to 800)

Both are released under the SIL Open Font License 1.1, which allows bundling
them with software. The files are the latin subsets Google Fonts serves.
